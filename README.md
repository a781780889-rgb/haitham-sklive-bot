# 🚀 نظام الأعذار الطبية

## ⚡ البدء السريع (3 خطوات)

### 1. التثبيت:
```bash
chmod +x install.sh
./install.sh
```

### 2. تحديث التوكن:
```bash
nano .env
# غيّر: BOT_TOKEN=توكن_البوت_من_BotFather
```

### 3. التشغيل:
```bash
chmod +x start.sh
./start.sh
```

---

## 🌐 الوصول

- **البوت:** على تيليجرام  
- **الموقع:** http://localhost:5000

---

## 🛠️ الأوامر

```bash
./start.sh  # التشغيل
./stop.sh   # الإيقاف
```

---

## 🔧 حل المشاكل

```bash
# فحص السجلات
tail -f logs/bot.log

# إعادة التشغيل
./stop.sh && ./start.sh
```
