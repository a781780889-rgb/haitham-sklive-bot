## 💻 استخدام Python API

```python
import hospital_management as hm

# إضافة مستشفى
hospital_id = hm.add_hospital(
    name="مستشفى الجديد",
    city="الرياض",
    region="الرياض",
    phone="0112345678"
)

# إضافة طبيب
doctor_id = hm.add_doctor(
    name="د. أحمد محمد",
    specialty="طب عام",
    hospital_id=hospital_id
)

# الحصول على جميع المستشفيات
hospitals = hm.get_all_hospitals()

# الحصول على أطباء مستشفى
doctors = hm.get_doctors_by_hospital(hospital_id)
```
