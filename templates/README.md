# قوالب قسم مرافق مريض

يحتوي هذا المجلد على القوالب الخاصة بقسم **مرافق مريض**.

## القالب العام بصيغة PDF

الملف `companion-sick-leave-template.pdf` هو نسخة PDF ثابتة من النموذج المرجعي المرفق، ومهيأة لإعادة الاستخدام أو الرفع من لوحة إدارة القوالب في قسم مرافق مريض. لا يحتوي الملف على بيانات شخصية أو حقولاً ثابتة مرتبطة بمريض بعينه.

## القالب المستخدم أثناء الإصدار الآلي

يبقى `companion-sick-leave-template-clean.html` هو مصدر القالب الديناميكي الذي تعبئه خدمة `companion_pdf_gen.py` ثم تحوله إلى PDF عند إصدار التقرير. تمت إضافة ملف PDF العام كأصل مستقل للقسم فقط، لذلك **لم يتغير مسار الإصدار الآلي أو منطق التنقل أو تخزين الطلبات**.

## إعادة إنشاء ملف PDF

من جذر المستودع يمكن إعادة إنشاء الملف من الصورة المرجعية المتاحة أثناء التطوير عبر الأمر التالي:

```bash
python3 tools/create_companion_template_pdf.py
```

يُحفظ الناتج دائماً في:

```text
templates/companion-sick-leave-template.pdf
```
