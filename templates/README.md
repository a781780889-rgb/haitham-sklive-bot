# قالب قسم مرافق مريض

يستخدم قسم **مرافق مريض** قالب PDF ثابتاً ورسميّاً واحداً فقط هو:

```text
templates/companion-sick-leave-template.pdf
```

يحتفظ المولّد بالصفحة الأصلية للقالب كما هي، ثم يضيف البيانات الديناميكية في الخانات المخصصة لها ويدمجها مع الصفحة الأصلية دون إعادة بناء التصميم أو تغيير المقاس أو الشعارات أو الحدود أو الألوان.

## الحقول الديناميكية

يتم ربط بيانات الطلب بالحقول التالية: رمز الإجازة، مدة الإجازة، تاريخ الدخول، تاريخ الخروج، تاريخ إصدار التقرير، اسم المرافق، رقم الهوية/الإقامة، الجنسية، صلة القرابة، جهة العمل، اسم الطبيب المعالج، والمسمى الوظيفي. وتُعرض الحقول الثنائية بالإنجليزية والعربية حيث يحدد القالب ذلك.

## التحقق

يمكن تشغيل اختبار الإصدار من جذر المشروع:

```bash
python3 -m unittest tests.test_companion_pdf_gen
```

لا يعتمد مسار الإصدار الآلي على أي قالب HTML أو على `default_template.pdf` أو `templates NEE.pdf`؛ تلك المسارات تخص أقساماً أخرى ولا تُستخدم في قسم مرافق مريض.
